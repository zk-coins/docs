# zkCoins Docs

Documentation for [docs.zkcoins.app](https://docs.zkcoins.app) — Shielded CSV protocol, architecture, wallet guide, and API reference.

## Stack

- Docusaurus 3.9.2
- Deployed via Cloudflare Pages

## Development

```bash
npm install
npm start    # http://localhost:3092
```

## Build

```bash
npm run build
npm run serve
```
